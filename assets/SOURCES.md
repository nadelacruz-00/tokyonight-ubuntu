# Vendored asset origins

Every file under `assets/` is vendored; `checksums.sha256` pins them.
`tools/regen-assets.sh` regenerates the Rewaita files and the checksum list.

| Path | Origin | Licence |
|------|--------|---------|
| `rewaita/{tokyonight,storm}/gtk4.css` | Generated by Rewaita (flatpak `io.github.swordpuffin.rewaita`) with `--theme --theme=tokyonight` / `tokyonight-storm`: `~/.config/gtk-4.0/gtk.css` | Rewaita GPL-3.0-or-later (metainfo `project_license`); palette by folke/tokyonight.nvim, MIT |
| `rewaita/{tokyonight,storm}/gtk3.css` | Same run: `~/.config/gtk-3.0/gtk.css` | as above |
| `rewaita/{tokyonight,storm}/gnome-shell.css` | Same run: `~/.local/share/themes/rewaita/gnome-shell/gnome-shell.css` | as above |
| `omp/tokyonight_storm.omp.json` | oh-my-posh theme (`tokyonight_storm`), https://github.com/JanDeDobbeleer/oh-my-posh/tree/main/themes | MIT, notice in [`LICENSES/oh-my-posh-MIT.txt`](../LICENSES/oh-my-posh-MIT.txt) |
| `osk/gjsosk-theme-sync@nadelacruz-00.github.io/*` | Own extension (nadelacruz-00), colours the GJS OSK keyboard from the Rewaita GTK 4 palette; maintained in `~/Development/gjs-osk-gboard/theme-sync/` | Same licence as this repository |
| `osk/gjsosk-split-flush`, `osk/99erhai-gjsosk-split-flush` | Own apt-hook patch for GJS OSK (https://github.com/vishram1123/gjs-osk) split-keyboard spacing; from `~/Development/gjs-osk-gboard/patch/` | Same licence as this repository (patches a GPL-3.0 upstream file at install time; no upstream code is copied) |

Downloads (not vendored, pinned in `checksums.sha256`): JetBrainsMono Nerd Font
v3.5.1 (OFL-1.1) and oh-my-posh v31.8.0 `posh-linux-arm64` (MIT).

Note: GJS OSK ships no licence file in the installed extension directory; its
upstream repository is GPL-3.0.
