# tokyonight-ubuntu — Design

Date: 2026-10-29
Status: approved in brainstorming, pending written-spec review

## 1. Intent

A public GitHub repo (`nadelacruz-00/tokyonight-ubuntu`, GPL-3.0) with an
idempotent, reversible `install.sh` that reproduces the owner's Tokyo Night
desktop look on a fresh **Ubuntu 26.04 aarch64 GNOME** install: Rewaita GTK
and Shell themes, Ptyxis terminal, Nerd Font, oh-my-posh prompt, tool themes
(zellij, lig), wallpaper, GJS OSK keyboard theme/layout (when present) and,
opt-in, the GDM login screen.

**Success criteria**

- One command (`./install.sh`) gives the full user-level look on a clean
  machine; `./install.sh --system` adds the root-level parts.
- Re-running makes zero changes; `--uninstall` restores the prior state.
- No personal information in the repo or its history (enforced by test).
- Comprehensive automated tests (unit, static, PII, integration in an
  `ubuntu:26.04` arm64 container) run in CI and must be green.

**Non-goals**

- Installing zsh, oh-my-zsh, zellij or lig, or changing the login shell.
- Copying any non-theme config (keybindings, bookmarks, sessions, `.zshrc`
  content outside a marked block).
- Supporting other distros, releases or architectures (`--force` exists to
  bypass preflight, unsupported).
- Automatic GDM rebuild on wallpaper/theme change.

## 2. Decisions taken

| Topic | Decision |
|---|---|
| Target | Any Ubuntu 26.04 aarch64 GNOME machine; erhai (OnePlus Pad 3) extras auto-detected |
| Rewaita | Ship generated CSS as source of truth **and** install Rewaita Flatpak + seed `prefs.json` |
| Variants | `tokyonight` (default, Rewaita "Tokyonight 🗼") and `storm` (Rewaita "Tokyonight Storm 🌪️") |
| Wallpaper | Stock `/usr/share/backgrounds/osselo-Ask_a_friend.jpg` from `ubuntu-wallpapers-resolute`; nothing bundled |
| Terminal | Ptyxis + JetBrainsMono Nerd Font + oh-my-posh Tokyo Night Storm prompt via marked rc blocks; zellij/lig `theme` line only if already installed |
| Root changes | Opt-in via `--system` (apt packages, GDM theme, erhai OSK split-flush apt hook) |
| Implementation | Bash orchestration + stdlib-only Python 3 helpers |
| Tests | bats-core (vendored submodules), Python `unittest`, shellcheck, shfmt, PII scan, container integration in GitHub Actions |

## 4. CLI

```
./install.sh [options]
  --variant tokyonight|storm   colour variant (default tokyonight)
  --system                     also run root-level parts (sudo)
  --only a,b | --skip a,b      module selection (names without number prefix)
  --dry-run                    print actions, change nothing
  --uninstall [--backup TS]    restore newest (or given) backup
  --purge                      with --uninstall: also remove flatpak/fonts/oh-my-posh installed by us
  --status                     per-module: applied / drifted / not applicable
  --offline                    use download cache only
  --strict                     stop at first module failure
  --force                      bypass OS/arch/desktop preflight
  -y|--yes  -v|--verbose  -h|--help  --version
```

Invalid combinations (`--only` with `--skip`, `--purge` without
`--uninstall`, unknown module, unknown variant) exit 2 with a message.

Exit codes: 0 success, 1 one or more modules failed, 2 usage error,
3 preflight failure, 4 lock held.

## 5. Modules

All paths below are relative to `$HOME` unless absolute. "Applies" =
precondition; when false the module is reported `SKIPPED (reason)`.

### preflight (always)
Checks `/etc/os-release` `ID=ubuntu`, `VERSION_ID=26.04`, `uname -m` =
`aarch64`, `XDG_CURRENT_DESKTOP` contains `GNOME` (or `gnome-shell`
installed when no session). Refuses EUID 0. Requires `python3`, `gsettings`,
`dconf`, `curl`, `sha256sum`, `install`, `flock`. Checks ≥200 MB free in
`$HOME`. Sets detection vars: `IS_ERHAI` (erhai gresource or
`oneplus-erhai-desktop` package), `HAS_ZSH`, `HAS_BASH_RC`, `HAS_ZELLIJ`,
`HAS_LIG`, `HAS_FLATPAK`, `HAS_PTYXIS`, `HAS_GJSOSK`, `HAS_SESSION_BUS`.

### fonts
Download pinned JetBrainsMono Nerd Font release zip, verify SHA-256,
extract `*.ttf` to `.local/share/fonts/JetBrainsMonoNerd/`, `fc-cache -f`
that dir. Check = all expected files present with expected hashes.

### rewaita (applies: flatpak present and not --offline)
Ensure user `flathub` remote (`flatpak remote-add --user --if-not-exists`),
`flatpak install --user -y flathub io.github.swordpuffin.rewaita`. Merge into
`.var/app/io.github.swordpuffin.rewaita/data/prefs.json` via `prefs.py`:
`dark-theme` = variant filename (`Tokyonight 🗼.css` / `Tokyonight Storm 🌪️.css`),
`light-theme` = `Tokyonight 🗼.css`, `window-controls` = `mint`,
`accent` = `'blue'`, `modify-gtk3-theme` = true, `modify-gnome-shell` = true.
Other keys preserved. `--system` installs `flatpak` via apt when missing.

### gtk
Install `assets/rewaita/<variant>/gtk4.css` → `.config/gtk-4.0/gtk.css`,
`gtk3.css` → `.config/gtk-3.0/gtk.css`. gsettings
`org.gnome.desktop.interface`: `color-scheme 'prefer-dark'`,
`accent-color 'purple'`, `gtk-theme 'Yaru-purple-dark'`,
`icon-theme 'Yaru-purple-dark'`.

### shell-theme (applies: user-theme extension installed)
Install `gnome-shell.css` → `.local/share/themes/rewaita/gnome-shell/gnome-shell.css`.
`gnome-extensions enable user-theme@gnome-shell-extensions.gcampax.github.com`
(falls back to appending to `org.gnome.shell enabled-extensions` when no
session). Set `org.gnome.shell.extensions.user-theme name 'rewaita'`.
`--system` installs `gnome-shell-extensions` when missing.

### wallpaper (applies: wallpaper file exists, or --system)
`--system` installs `ubuntu-wallpapers-resolute` when the file is missing.
Set `org.gnome.desktop.background picture-uri`, `picture-uri-dark`,
`picture-options 'zoom'` and `org.gnome.desktop.screensaver picture-uri` to
`file:///usr/share/backgrounds/osselo-Ask_a_friend.jpg`.

### ptyxis (applies: ptyxis installed)
Use `org.gnome.Ptyxis default-profile-uuid` if set, else generate a new
32-hex UUID (`python3 -c uuid4().hex`) and add it to `profile-uuids`.
Profile path `/org/gnome/Ptyxis/Profiles/<uuid>/`: `palette` =
`'Tokyo Night'` (tokyonight) or `'Tokyo Night Storm'` (storm, from
`assets/ptyxis/tokyonight-storm.palette` → `.local/share/org.gnome.Ptyxis/palettes/`).
Global: `font-name 'JetBrainsMono Nerd Font 10'`, `use-system-font false`,
`interface-style 'dark'`.

### prompt
Download pinned oh-my-posh `posh-linux-arm64`, verify SHA-256, install to
`.local/bin/oh-my-posh` (0755). Install `omp/tokyonight_storm.omp.json` →
`.config/oh-my-posh/`. Marked block in `.zshrc` (if zsh installed or
`.zshrc` exists) and `.bashrc` (if exists):
```
# >>> tokyonight-ubuntu >>>
command -v oh-my-posh >/dev/null && eval "$(oh-my-posh init <shell> --config ~/.config/oh-my-posh/tokyonight_storm.omp.json)"
# <<< tokyonight-ubuntu <<<
```
If an unmarked `oh-my-posh init` line already exists, it is left alone and
the block is not added (avoids double init); reported as `already configured`.
zellij (if installed and `.config/zellij/config.kdl` exists): replace the
uncommented top-level `theme "..."` line with `theme "tokyo-night-storm"`
(append if absent). lig (if installed and `.config/lig/config.toml` exists):
set `theme = "tokyonight"` under `[ui]`.

### osk (applies: gjsosk@vishram1123.com extension installed)
Install theme-sync extension to `.local/share/gnome-shell/extensions/<uuid>/`,
enable it. Write gjsosk settings (via the extension's own schema dir):
`custom-layout` from `assets/osk/layouts.json`, `layout-landscape 12`,
`layout-portrait 12`, `landscape-width-percent 48`,
`landscape-height-percent 28`, `portrait-width-percent 100`,
`portrait-height-percent 35`, `outer-spacing-px 6`, `border-spacing-px 2`,
`font-size-px 16`, `font-bold true`, `round-key-corners false`,
`show-icons false`, `system-accent-col false`. **Never** writes
`default-monitor`. With `--system` on erhai: install split-flush hook
(`/usr/local/sbin/gjsosk-split-flush` + `/etc/apt/apt.conf.d/99erhai-gjsosk-split-flush`).

### gdm (applies: --system)
`gresource.py` builds `gnome-shell-theme.gresource` from base
`/usr/share/gnome-shell/theme/erhai/gnome-shell-theme.gresource` if present,
else Yaru's, embedding the wallpaper and appending the Tokyo Night override
block (palette from `assets/rewaita/<variant>/gtk4.css`) to
`Yaru/gnome-shell-dark.css`, `Yaru/gnome-shell.css`, `gdm.css`. Requires
`glib-compile-resources`, `gresource` (`libglib2.0-dev-bin`, installed under
`--system`). Install to `/usr/share/gnome-shell/theme/tokyonight-ubuntu/`,
`update-alternatives --install /usr/share/gnome-shell/gdm-theme.gresource gdm-theme.gresource <dest> 150`.
Remove = `update-alternatives --remove` + delete dir.

## 6. Safety and error handling

- `set -Eeuo pipefail`, `IFS=$'\n\t'`, `umask 022`, `shopt -s inherit_errexit`.
- `ERR` trap: module, file:line, command, log path.
- Log: `.local/state/tokyonight-ubuntu/logs/<UTC-ts>.log`; console summary
  table (module, result, changes).
- Lock: `flock -n` on `.local/state/tokyonight-ubuntu/lock` (exit 4 if held).
- Each module runs in a subshell; failure is recorded and other modules
  continue unless `--strict`. Modules declare dependencies (gdm → wallpaper
  asset path only, not module success).
- **Backups**: `.local/state/tokyonight-ubuntu/backups/<UTC-ts>/manifest.tsv`
  rows: `file<TAB>path<TAB>backup-relpath|ABSENT`,
  `gsetting<TAB>schema[:path]<TAB>key<TAB>old-value|UNSET`,
  `dconf<TAB>key<TAB>old|UNSET`, `block<TAB>file`, `ext<TAB>uuid<TAB>was-enabled`,
  `alt<TAB>name<TAB>path`, `pkg<TAB>kind<TAB>name` (installed by us). Manifest
  is appended+fsynced per change so an interrupted run is still reversible.
- Writes are atomic (temp file in same dir + `mv`), preserving mode of the
  target when replacing. Unchanged content → no write, no manifest row.
- **Uninstall** replays the manifest in reverse; `--purge` additionally
  removes `pkg` rows (flatpak app, font dir, oh-my-posh binary). Apt packages
  are never removed automatically (printed as a hint).
- **Downloads**: `curl --fail --location --proto '=https' --tlsv1.2 --retry 3
  --retry-delay 2`, into `.cache/tokyonight-ubuntu/`, verified against
  `assets/checksums.sha256` before use; mismatch = hard failure and the cache
  file is deleted.
- **Privilege**: never as root; `--system` does one `sudo -v` and uses
  `sudo` only for apt-get, install into `/usr` or `/etc`, update-alternatives.
  Without `--system` nothing outside `$HOME` is written (test-enforced).
- No session bus: gsettings calls are wrapped in `dbus-run-session`, warning
  that a re-login is required.
- Paths with spaces and emoji (Rewaita filenames) are always quoted; tests
  cover them.

## 7. PII policy

Excluded: usernames, real names, email addresses, home-directory paths,
hostnames, GTK bookmarks, Ptyxis session state and profile UUIDs, monitor
connector names, machine IDs, MAC/serial numbers, any `.zshrc` content.
The only identity in the repo is the GitHub handle in URLs, `metadata.json`
`uuid`/`url` of the owner's extension, and CREDITS.

`pii_scan.py` patterns: emails (allowlist `noreply@anthropic.com`,
`*@users.noreply.github.com`), `/home/[^/\s$]+`, `/Users/`, 32-hex and
8-4-4-4-12 UUIDs outside an allowlist (`checksums.sha256`), MAC addresses,
IPv4 outside RFC 5737 docs ranges, plus literal strings from a gitignored
`.pii-denylist` (example committed). Runs on the working tree in `make test`
and on full git history in CI.

## 8. Testing

**bats-core** (submodules `tests/bats/{bats-core,bats-support,bats-assert,bats-file}`):
- Each test: fresh `HOME=$BATS_TEST_TMPDIR/home`, `XDG_*` under it, stubs
  first on `PATH`. Stubs (`gsettings`, `dconf`, `gnome-extensions`,
  `flatpak`, `apt-get`, `dpkg`, `sudo`, `curl`, `fc-cache`,
  `update-alternatives`, `glib-compile-resources`, `gresource`, `uname`,
  `ptyxis`, `zellij`, `lig`, `zsh`) log argv to `$STUB_LOG` and keep state in
  `$STUB_STATE` (gsettings as a flat key=value store). `OS_RELEASE_FILE`
  override for preflight.
- Library tests: block insert/replace/remove, duplicate/missing markers, CRLF,
  no trailing newline; atomic_write mode preservation; manifest round-trip
  incl. spaces/emoji/tabs-rejected; settings wrapper records UNSET vs value.
- CLI tests: every flag, invalid combos and exit codes, `--help`,
  `--dry-run` produces zero filesystem/stub mutations.
- Per module: applies/skip conditions; apply on clean HOME; apply over
  existing user config (backed up, unrelated keys/lines preserved); second
  apply = no changes and no new manifest rows; remove restores byte-for-byte
  and gsettings to previous/unset; both variants.
- Failure tests: checksum mismatch aborts module and deletes cache file;
  one module failing doesn't stop others (and `--strict` does); kill
  mid-run leaves replayable manifest; EUID 0 refused; lock held → exit 4;
  read-only target file → clear error.
- Boundary guard: without `--system`, `sudo`/`apt-get`/`update-alternatives`
  stubs never called and no argv contains `/usr/`, `/etc/`, `/var/`.

**Python `unittest`** for each helper: palette extraction for both variants
and malformed input; prefs merge preserves unknown keys, handles missing
file and invalid JSON (backup + error); gresource XML/CSS golden files;
pii_scan detects planted fixtures and respects allowlists.

**Static**: `shellcheck -x -S style`, `shfmt -d -i 2 -ci`, `python3 -m py_compile`,
`ruff check` when available; `sha256sum -c assets/checksums.sha256` for
vendored assets; anchor-colour assertions (`#1a1b26` in tokyonight,
`#24283b` in storm gtk4.css).

**Integration** (GitHub Actions, `ubuntu-24.04-arm`, container `ubuntu:26.04`):
1. apt install `dconf-cli dbus libglib2.0-bin libglib2.0-dev-bin python3 curl
   zsh ptyxis gnome-shell-extensions ubuntu-wallpapers-resolute fontconfig`.
2. Non-root user; snapshot HOME tree + `dconf dump /`.
3. `dbus-run-session ./install.sh -y --skip rewaita`; assert real dconf
   values and files.
4. Re-run → summary reports 0 changes.
5. `--uninstall` → HOME tree and dconf dump equal the snapshot.
6. Repeat with `--variant storm`; then `--system` with a stub-free GDM build
   asserting the update-alternatives result.
7. Separate job (`continue-on-error`): real Flathub Rewaita install + real
   downloads with cache.

`make test` = static + PII + bats + python. `make test-container` runs the
integration flow locally via podman/docker when available.

**PII rules for screenshots** (checked before commit):
- Captured under a throwaway demo account (`demo`, hostname `ubuntu`) so the
  prompt, top bar and GDM user list show no real name/handle; the
  oh-my-posh segments that show user/host are visible but generic.
- No personal files, browser tabs, notifications, Wi-Fi SSIDs, calendar
  entries or clipboard history in frame; terminal shows only a demo repo.
- `tools/screenshots.sh` runs `tesseract` OCR (when installed) on each image
  and feeds the text to `pii_scan.py` with the denylist; a CI test checks
  that every image referenced from README exists, is ≤ 1.5 MB, and that
  `docs/screenshots/` has no EXIF/text chunks (`python3` PNG chunk check;
  only IHDR/IDAT/IEND/PLTE/tRNS/sRGB/gAMA/pHYs allowed).
